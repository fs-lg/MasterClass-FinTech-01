Customer Credit Scoring Project

Credit Scoring Team – Part AI Company

📋 Project Summary

Designing, implementing, and evaluating an intelligent model to predict the probability of customer default and to rank credit risk, based on the raw "German Credit Dataset."

🛠️ Task 1: Data Cleaning & Exploratory Data Analysis (EDA)

[ ] 1.1 Data Loading and Initial Preparation

Loading the raw data file (`german.data`).

Assigning column names based on the documentation (`german.doc`) for 20 features.

Encoding the target variable: 0 for "Good" (reliable) customers and 1 for "Bad" (defaulting/unreliable) customers.

[ ] 1.2 Data Quality and Type Assessment

Distinguishing between numerical features (7 features) and categorical features (13 features).

Identifying and reporting missing values.

[ ] 1.3 Distribution Analysis and Outlier Detection

Analyzing the distributions of key numerical features (e.g., "Credit Amount" and "Duration") using boxplots and histograms.

Identifying outliers without altering the target variable.

[ ] 1.4 Correlation and Association Analysis

Calculating the correlation matrix for numerical variables and generating a heatmap.

Analyzing the relationship between key categorical features (e.g., "Checking Account" and "Credit History") and the target variable using crosstabs and stacked charts.

[ ] 🎯 Expected Deliverables for Task 1:

A written report detailing the number of samples, the number of features, and the class imbalance ratio of the target variable. At least 2 key charts, accompanied by textual analysis, illustrating the initial relationship between raw features and default.
